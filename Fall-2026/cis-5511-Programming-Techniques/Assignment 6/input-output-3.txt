PT_06 - Word AVL tree: actual interactive input/output
Run: python word_avl.py

This extends the PT_05 tree_* interface. Repeated keys are ignored.
Search returns membership (0 or 1). Insert/delete return membership before
that operation. Height: empty = -1, leaf = 0. h = height; bf = left - right.

The session first replays the commands from the submitted PT_05 sample.
It then tests LL, RR, LR, and RL insertion, deletion with heavy-child balance
zero in both directions, and deletion requiring repairs at two distinct nodes.
The tree is emptied between scenarios. For the sequence j a b l e h g d k i f c,
deleting h requires an RL repair at j and then an LL repair at i.

Terminal input echo is reproduced; all program output is captured from main().
